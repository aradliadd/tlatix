# תלתיקס – אתר

האתר של תלתיקס (tlatix.co.il), מתארח ב-GitHub Pages.

- `index.html` – דף הבית
- `accessibility.html` – הצהרת נגישות
- `privacy.html` – מדיניות פרטיות
- `styles.css` – עיצוב משותף
- `img/` – תמונות
- `CNAME` – הדומיין של האתר

טופס יצירת הקשר נשלח ל-info@tlatix.co.il דרך FormSubmit (AJAX). בשליחה הראשונה FormSubmit שולח מייל אימות ל-info@ – צריך ללחוץ על הקישור שבו פעם אחת.

## החנות
- `shop.html` – עמוד החנות הראשי (4 מוצרים מכל קטגוריה + כפתור לעמוד הקטגוריה)
- `shop-home.html`, `shop-baby.html`, `shop-car.html`, `shop-office.html`, `shop-garden.html` – עמוד מלא לכל קטגוריה, עם מיון לפי מחיר
- `products.js` – **כאן מוסיפים ועורכים מוצרים** (הוראות בראש הקובץ). תמונות מוצרים שמים ב-`img/products/`
- `shop.js` – הקוד שמציג את המוצרים (אין צורך לגעת בו)

כפתור "להזמנה" מוביל לטופס בדף הבית וממלא בו מראש את שם המוצר והמחיר.
מוצרים עם `demo: true` הם דוגמאות – למחוק לפני העלייה לאוויר.
